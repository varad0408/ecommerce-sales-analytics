# E-Commerce Sales Analysis

This is an e-commerce sales analysis project that I worked on using SQL, Power BI and Tableau.

I used the data to understand sales, orders, customers, products and delivery performance. I first worked with the data in MySQL and used SQL queries to perform the analysis. I then used Power BI and Tableau to create dashboards and present the results.

## Tools Used

MySQL
SQL
Power BI
Tableau

## What I Analyzed

I looked at different parts of the data, including:

- Total sales and revenue
- Total orders and customers
- Average order value
- Sales by product category
- Top products by sales
- Monthly sales trends
- Orders by customer state
- Order status
- Top customers by spending
- Delivery performance
- On-time and late orders
- Average delivery time
